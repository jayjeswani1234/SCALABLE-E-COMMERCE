# AI Resume Analyzer

An AI-powered Resume Screening and Recruitment Platform built using the MERN Stack. The platform helps recruiters analyze resumes, rank candidates, manage job applications, and streamline the hiring process using Artificial Intelligence.

---

## Features

- AI-powered Resume Analysis
- Resume Upload (PDF/DOCX)
- Candidate Ranking System
- Job Posting & Management
- Recruiter Dashboard
- Applicant Tracking
- Authentication & Authorization (JWT)
- Responsive UI
- Search & Filter Candidates
- Profile Management
- Admin Dashboard
- Secure REST APIs

---

## Tech Stack

### Frontend
- React.js
- Redux Toolkit
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js

### Database

### AI & Utilities
- Resume Parsing

## Installation

### Clone Repository

```bash
git clone https://github.com/jayjeswani1234/AI-resume-Analyzer.git
```

### Install Dependencies

Backend

```bash
npm install
```

Frontend

```bash
cd frontend
npm install
```

---

## Environment Variables

Create a `.env` file inside the backend directory.

```env
PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret_key

NODE_ENV=development
```

---

## Run the Project

Backend

```bash
npm run server
```

Frontend

```bash
cd frontend
npm start
```

Run both simultaneously

```bash
npm run dev
```
